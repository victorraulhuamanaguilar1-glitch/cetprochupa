# CETPRO Conrado Kretz Lenz – Chupa

Sitio web oficial del Centro de Educación Técnico-Productiva de Chupa (Azángaro, Puno), código modular 1027291.

- **Inicio**: especialidades, pasos de matrícula, comunicados y contacto.
- **Matrícula en línea** (`matricula.html`), **mesa de partes virtual** (`tramites.html`) y **pagos** (`pagos.html`).

Para cambiar textos, tarifas, especialidades o comunicados edite solo `assets/js/config.js`.
Los formularios guardan los trámites en Google Sheets mediante Google Apps Script (`urlServidor` en `config.js`).
